# Optimization problem

Generate a new empty
[OptimizationProblem](https://prioritizr.github.io/oppr/reference/OptimizationProblem-class.md)
object.

## Usage

``` r
new_optimization_problem()
```

## Value

An
[OptimizationProblem](https://prioritizr.github.io/oppr/reference/OptimizationProblem-class.md)
object.

## Examples

``` r
# create empty OptimizationProblem object
x <- new_optimization_problem()

# print new object
print(x)
#> optimization problem (empty)
```
